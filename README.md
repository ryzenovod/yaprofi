# Я — ПРОФЕССИОНАЛ · Рынок

Статический пульт ведущего для игры «Рынок» X сезона. Сайт помогает вести 6 команд и 6 раундов, менять цены трёх рынков и выводить отдельный экран для проектора. Деньги и активы команды передают друг другу самостоятельно.

GitHub Pages: https://ryzenovod.github.io/yaprofi/

## Что внутри

- консоль ведущего с раундами, фазами, таймером, командами и текущими ценами;
- цены могут уходить в минус, а физические сделки между командами остаются частью игры;
- справочник из 12 рыночных событий сохранён как игровая опора;
- экран проектора открывается в том же браузере через `?display=1` и показывает раунд, фазу, таймер, цены и новость рынка; капитал и секретные задачи остаются в пульте;
- экспорт и импорт JSON-сессий совместимы со старым форматом сохранений v2.

Оформление использует Gotham Book/Bold/Black, шесть цветов из брендбука X сезона, официальный знак и фон из предоставленного стартер-пака. Шрифты загружаются из `assets/fonts/`, внешнего сервиса шрифтов нет.

Справочник тактик и задач совпадает с новой печатной редакцией. Ранние действия занимают ход карты; коррекции компонентов идут в порядке Стоп → Хедж → Лоббист. «Опцион» разрешает одну добровольную сделку с одним жетоном после расчёта цен, до новости. Ведущий считает эффекты карт по правилам и вручную вносит итоговые изменения в пульт; сайт автоматически применяет только выбранную новость.

## Локальный запуск

```bash
python3 -m http.server 8765
```

Откройте `http://127.0.0.1:8765/`. Для проектора используйте `http://127.0.0.1:8765/?display=1`.

## Проверка

```bash
node tests/smoke.cjs
```

Для smoke-тестов нужен Playwright. Его можно поставить без записи в production dependencies:

```bash
npm install --no-save --package-lock=false playwright
npx playwright install chromium
```

Если Playwright уже установлен в другом месте, передайте путь через `PLAYWRIGHT_MODULE`.

## Публикация

Workflow GitHub Pages на `main` собирает только статические файлы в `_site`: `index.html`, `styles.css`, `app.js` и `assets/`.
